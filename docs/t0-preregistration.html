T0 사전 등록 — NCS의 계산적 해부

연구진 정진수(제1) · 류한철(교신) · 등록 초안 v0.1 · 2026-09-09 · 확증 분석 착수 전 · 데이터: NCS 릴리스 2026-02 전수(ncs 스키마) + 직업기초능력
상태: 등록 초안(협의용). 이 문서가 커밋되는 시점의 해시가 가설 동결 시점이다. 이후 변경은 §9 수정 이력에 날짜와 사유를 남기며, 확증 분석은 동결 후에만 시작한다. 모든 수치 관찰은 EA11(2026-09-09) 탐색에서 온 것이며, 이 문서의 가설은 그 탐색을 본 뒤 형성됐다 — §2가 그 처리 규칙이다.

0 · POSITION이 논문의 자리 — 연구 프로그램의 앵커

2026-09-09 세미나에서 지도교수는 세 가지를 요청했다: NCS 자체를 먼저 분석할 것, 가설을 세분화할 것, 가설마다 공학적 기여를 분명히 할 것. T0는 그 응답이다. 프로그램은 T0(데이터를 아는가) → T1(후보를 만들고 믿게 하는가) → T3(구조가 쓸모 있는가) → T6(사회적 함의)로 재배열되며, T0는 앞선 두 논문이 의존하는 사실을 확정한다: 규칙이 어디까지 닿고 LLM이 어디서 필요한지, 정규화로 물량이 얼마나 주는지, 표준의 어느 부분이 낡았는지.

T0의 결정적 성질. 기술 통계이므로 전문가 골드도, LLM 판정도 필요 없다. 검증 의존성(docs/validation-dependency.md) 밖에 있는 유일한 논문이며, 따라서 프로그램에서 가장 먼저 투고 가능하다. 수치의 계층 라벨은 '원천 실측(data fact)'이고, 모델이 개입하는 유일한 지점(H3 임베딩 정렬)은 별도 표기와 민감도 분석으로 다룬다.

1 · QUESTIONS & CONTRIBUTIONS연구 질문과 기여

RQ-A(공학). 국가 역량 표준은 데이터로서 어떤 규칙성·중복·파편화·구조를 갖는가, 그리고 그 성질은 기계 처리(규칙 vs 모델)의 경계와 비용을 어떻게 결정하는가?

규칙/모델 경계의 정량화구조화 가능성 지도(대분류×지표), 잔여 문장 유형 분류T1 파이프라인 설계, 유사 표준(ESCO·O*NET) 처리자
정규화 사전KSA 별칭 사전(CSV, 정규화 키·임베딩 클러스터·유형 불일치 표기)T1 정렬기, NCS 검색·매칭 서비스
표준 품질 감사중복·파편화·템플릿 이탈·유형 불일치 목록 — 대분류별 리포트표준 관리 기관(공단), 개정 실무
데이터 기반 분류 대조공유 KSA 기반 직무 유사도 그래프와 공식 분류의 일치도, 불일치 목록분류 체계 개편 논의, 전직 경로 서비스

2 · HONESTY PROTOCOL탐색–확증 분리 규칙

EA11에서 대분류(24) 수준의 집계를 먼저 보았다. 따라서 이 문서의 가설 일부는 사후 형성이다. 처리 규칙:

  • 라벨. 각 가설에 PEEK(대분류 집계를 본 뒤 형성 — 방향은 관찰에서 옴) 또는 CLEAN(탐색에서 계산하지 않은 지표 — 방향은 이론·선행 관찰에서 옴)을 단다. 논문 방법 절에 이 구분을 그대로 싣는다.
  • 분석 단위 이동. 확증 검정은 탐색이 보지 않은 해상도인 세분류(n=1,109)에서 수행한다. 대분류 내 분산은 미관찰이므로 검정의 정보량이 보존된다.
  • 반분. 세분류를 대분류 내에서 시드 고정(seed=20260909) 무작위 반분해 A/B 두 번 검정하고, 부호와 유의성이 일치할 때만 "지지"로 보고한다. 불일치는 그대로 보고.
  • 다중 비교. H1~H6·S1~S4를 하나의 가설군으로 두고 Benjamini–Hochberg FDR 5%를 적용한다.
  • 효과 크기 우선. n=1,109에서는 사소한 차이도 유의하므로, 보고의 중심은 효과 크기(ε², Cliff's δ, 상관계수)와 구간이며 p값은 보조다.
  • 평범한 설명 배제(§7). 사회적 해석(S-계열)은 대안 설명을 배제한 뒤에만 서술한다.

4 · HYPOTHESES — ENGINEERING공학 가설 H1–H6

H1

수행준거 문장은 단일 통사 템플릿에 거의 완전히 순응하며, 이탈은 국지적이다

PEEK
지표
템플릿 준수율 = "~수 있다"(공백·마침표 변형 허용)로 끝나는 수행준거 비율. 이탈 문장은 종결 형식별로 유형화(명사형 종결, 복수 절, 오타·잘림 등).
단위·검정
세분류별 준수율. 전체 비율의 95% 신뢰구간; 대분류 간 Kruskal–Wallis + ε². 이탈 집중도: 이탈의 50%를 담는 최소 세분류 수(로렌츠 집중).
사전 기대
전체 ≥ 99%; 이탈의 절반 이상이 소수 세분류(≤ 5%)에 집중. EA11 관찰: 대분류 22/24가 99.3~99.8%, 경비·청소 86.6%.
공학적 기여
규칙 파서의 커버 범위 확정과 잔여 유형 목록 → "규칙이 끝나고 모델이 필요한 경계"의 위치·크기. T1 수행준거 분해(T4)의 사전 커버리지.
대안 설명
이탈이 특정 개발 연도·개발 주체의 작성 지침 차이일 가능성 — H5 연도와 교차표로 확인.
H2

KSA 중복률은 산업에 따라 체계적으로 다르며, 규모를 통제해도 남는다

PEEK
지표
고유 문장 비율 = 세분류 내 distinct(KSA description) / count. 보조: 유형(K/S/A)별 비율.
단위·검정
세분류별. 규모 통제 필수: 고유 비율은 집합 크기에 의존하므로 log(KSA 수)를 공변량으로 한 회귀 후 대분류 잔차 효과(ANCOVA/혼합모형). 반분 검정.
사전 기대
규모 통제 후에도 대분류 효과 유의, 제조·기술 계열이 서비스·경영 계열보다 낮은 고유 비율. EA11: 기계 10.4% ~ 영업판매 22.2%.
공학적 기여
정규 사전 크기와 산업별 중복 제거 계수(5~10×) → T1 판정 물량·비용의 하한. 작성 관행(템플릿 복제)의 정량 증거.
대안 설명
세분류당 능력단위 수가 많을수록 중복이 커지는 구조적 효과 — 능력단위 수도 공변량에 포함.
H3

동일 개념이 다수 표기로 파편화되어 있으며, 파편화는 규칙 정규화만으로 절반 이상 회수된다

CLEAN (사례만 관찰)
지표
① 규칙 정규화 키(공백 제거, 역할 접미사 '능력/기술/지식/태도/의지/노력/…하려는 태도' 제거, 조사·기호 정리) ② 임베딩 클러스터(bge-m3, cos ≥ 0.90; 민감도 0.85/0.95). 파편화 지수 = 표면형 수 / 개념 클러스터 수. 회수율 = 규칙 키만으로 병합되는 표면형 비율 / 임베딩까지 병합되는 비율. 유형 불일치율 = 같은 정규화 키가 둘 이상의 K/S/A 유형에 등장하는 키의 비율.
단위·검정
대분류·세분류별 지수. 규칙 회수율 ≥ 50% 검정(단측 이항, 클러스터 단위). 유형 불일치는 비율과 상위 사례 목록.
사전 기대
고빈도 개념일수록 파편화가 크다(빈도-파편화 양의 순위상관). 규칙 회수율 50~70%, 나머지는 임베딩 필요. 관찰 사례: '안전 준수' 계열 8+ 표기(172/134/60/56/46/33/31개 직무), '보고서 작성 능력'(K, 100) vs '보고서 작성 기술'(S, 44).
공학적 기여
별칭 사전 산출물, 규칙/임베딩 역할 분담의 정량 근거(EA10 ④ "놓침은 정렬 실패"의 원천 측), 표준 품질 감사 항목.
모델 개입
임베딩 단계만 모델 의존 — 라벨 '모델 보조', 임계값 민감도 표 필수. 규칙 키 결과는 원천 실측.
H4

공유 KSA로 계산한 직무 유사도 군집은 공식 분류 체계와 부분적으로만 일치한다

CLEAN
지표
세분류×정규화 KSA 키 이분 그래프 → 세분류 간 Jaccard(보조: TF-IDF 코사인) → Louvain 군집(해상도 1.0, 시드 고정) → 공식 대분류(24)·중분류(81)와 NMI/ARI. 불일치 직무 목록(자기 대분류보다 타 대분류 군집에 가까운 세분류).
단위·검정
세분류 전수. 귀무 분포: 세분류 라벨 순열 1,000회로 NMI 영분포. 반분 대신 부트스트랩(KSA 표본 재추출) 안정성.
사전 기대(이론)
대분류 대비 NMI 0.3~0.6(중간 일치): 안전·문서·소통 같은 범용 KSA가 산업을 가로지르므로 완전 일치는 불가, 그러나 무작위보다 명확히 높음. 불일치는 융합 직무(예: 정보통신×문화·예술, 보건×사회복지)에 집중.
공학적 기여
LLM 없이 얻는 직무 유사도 네트워크(T6·전직 경로 서비스의 Layer 0.5), 분류 개편 논의의 정량 근거. 범용 KSA를 제거한 변형(IDF 가중)과의 비교로 "범용 역량 층"의 크기 추정.
H5

표준의 개정 신선도는 산업 간에 크게 불균등하다

PEEK
지표
능력단위 코드 접미 _YYvN → 최종 개정 연도(2000+YY), 버전 수 N. 세분류별 평균 개정 연도, 2022+ 비율, 평균 버전.
단위·검정
세분류별. 대분류 간 Kruskal–Wallis + ε²; 연도 분포의 지니 계수. 반분 검정.
사전 기대
대분류 효과 ε² ≥ 0.3(큰 효과). EA11: 2022+ 비율 65.2%(경영·회계·사무) ~ 0%(경비·청소·사업관리); 금융·보험 평균 ≈ 2015.
공학적 기여
신선도 가중 추출 우선순위(낡은 표준부터 재추출 → T1 스코프 선정 규칙), 공단 감사 리포트의 핵심 표.
대안 설명(필수 배제)
접미 연도가 '내용 개정'이 아니라 '코드 체계 개편'이나 '형식 재발행'을 반영할 가능성 — 공단 개정 이력 공지와 표본 대조(세분류 20개 무작위)로 확인 후에만 '신선도'로 해석. 확인 전에는 '코드 연도'로만 보고.
H6

디지털 어휘의 침투는 산업 간에 불균등하며, 최근 개정된 표준일수록 높다

PEEK(분포) · CLEAN(연도 교호)
지표
사전 선언 어휘 A: 디지털·데이터·인공지능·AI·소프트웨어·자동화·프로그램·전산. 민감도 어휘 B(A + IoT·빅데이터·클라우드·정보시스템·온라인·스마트). 세분류별 KSA 중 어휘 포함 비율.
단위·검정
분포: 대분류 간 Kruskal–Wallis. 교호: 대분류 내 세분류의 (평균 개정 연도 × 디지털 비율) Spearman, 대분류 고정효과 회귀. A·B 두 어휘로 결과 일치 여부 보고.
사전 기대
분포는 EA11 관찰(정보통신 10.86% ~ 경비·청소 0.24%). 교호는 미관찰: 대분류 내에서 개정 연도가 최근일수록 디지털 비율 높음(ρ > 0.2).
공학적 기여
H5와 결합한 '표준–현장 괴리 위험 지수'(디지털 요구 높음 × 개정 오래됨 — 예: 금융·보험) → 추출·개정 우선순위 및 T6 입력.
대안 설명
'프로그램'·'전산'의 다의성(교육 프로그램 등) — 어휘 A/B 민감도와 무작위 100건 수동 검토로 정밀도 보고.

5 · HYPOTHESES — SOCIAL사회 가설 S1–S4 (T0-b, 외부 데이터 결합)

S-계열은 같은 데이터에서 출발하지만 해석에 외부 자료가 필요하다. 별도 논문(T0-b)으로 분리할지 T0의 논의 절로 둘지는 M-T0-1(§8).

S1

표준의 수준 사다리는 산업별 경력 천장을 부호화하며, 외부 노동시장 지표와 상관한다

PEEK(분포) · CLEAN(외부 상관)
지표
세분류별 L5+ 능력단위 비율, 평균 수준, 최고 수준. 외부: 대분류→표준산업분류(KSIC) 대응표(작성 필요, M-T0-2) 후 산업별 평균 임금·대졸 비율(고용형태별근로실태조사 등).
검정
분포: 대분류 간 ε². 외부 상관: 대분류 수준 Spearman(n=24 — 저검정력, 기술적 보고), 세분류 수준은 대응표 해상도에 따라.
사전 기대
EA11: L5+ 비율 71.2%(금융·보험) ~ 9.1%(경비·청소), 평균 수준 5.03 ~ 3.11. 외부 상관 양(ρ > 0.4).
해석 경계
"표준이 계층을 반영한다"까지만; "재생산한다"는 인과 주장이므로 서술하지 않는다.
S2

국가가 요구하는 노동자의 태도는 '준수'가 지배적이며, 산업에 따라 담론 구성이 다르다

PEEK(상위 어휘) · CLEAN(범주 분포)
지표
태도(A) 항목 고유 문장에 사전 선언 코드북 적용: 준수/안전 · 의지·노력 · 인지(분석·전략·주의) · 대인(소통·친절·협력) · 윤리·책임 · 품질·정확 · 기타. 규칙 코딩 후 무작위 300건을 연구진이 이중 코딩(κ 보고).
검정
대분류×범주 카이제곱 + Cramér's V; 산업별 상위 범주.
사전 기대
전체 상위 = 준수(EA11: 안전사항·안전수칙·기술기준 준수가 1~3위). 서비스 계열은 대인 범주, 기술 계열은 준수·정확 범주 비중이 높다.
해석 경계
담론 분석적 서술은 T0-b(직업교육·HRD 저널)에서만; T0-a에서는 분포 보고에 그친다.
S3

개정 신선도는 산업 변화 속도보다 표준 개발 체계에 더 의존한다

CLEAN
지표
H5 개정 연도 vs 산업 변화 속도 대리변수(H6 디지털 비율, 외부: 산업별 고용 증감률). 개발 주체 변수: 공단 공개 자료의 산업별 협의체(ISC/SC) 정보(수집 가능 시).
검정
대분류 수준 Spearman; 개발 주체 정보가 있으면 주체별 개정 연도 분포 비교.
사전 기대
변화 속도와의 상관은 약함(|ρ| < 0.3) — 금융·보험(디지털 4.76%, 개정 ≈2015)이 반례의 전형. H5 대안 설명 배제 후에만 해석.
S4

격차는 겹친다 — 저수준·저디지털·저신선 산업이 동일하다

CLEAN
지표
대분류별 z(L5+ 비율)·z(개정 연도)·z(디지털 비율)의 순위 일치(Kendall's W)와 합성 지수.
사전 기대
W ≥ 0.5; 하위 3~5개 대분류(경비·청소, 음식서비스, 식품가공, 인쇄·목재·가구·공예, 재료)가 세 축 모두 하위. 기술적 보고, 인과 주장 없음.

7 · THREATS타당성 위협과 배제 계획

  • 코드 연도의 의미(H5·S3·S4의 전제). 공단 개정 공지와 20개 세분류 표본 대조로 '내용 개정' 여부 확인. 확인 실패 시 H5는 '코드 연도 분포'로 격하하고 S3·S4는 보류.
  • 규모 교란(H2). 집합 크기·능력단위 수 공변량 통제 없이는 보고하지 않는다.
  • 어휘 다의성(H6). 두 어휘 집합 + 수동 검토 100건.
  • 정규화 규칙의 자의성(H3). 규칙을 코드로 공개하고, 규칙 변형(접미사 목록 ±) 민감도를 보고.
  • 대분류 n=24의 저검정력(S1·S3). 대분류 수준 상관은 기술적 보고로 한정, 주 검정은 세분류 수준.
  • 사후 가설(§2). PEEK 라벨과 반분·단위 이동으로 처리, 방법 절에 명시.

8 · DECISIONS연구진이 정할 것 (M-T0)

ID결정선택지 / 제안
M-T0-1논문 분리(a) T0 단일 논문에 S-계열을 논의 절로 / (b) T0-a 공학 + T0-b 사회 두 편. 제안 (b) — 저널·심사자·서술 톤이 다르고, (a)는 두 독자 모두를 놓칠 위험.
M-T0-2외부 노동시장 자료대분류→KSIC 대응표 작성 방식과 임금·학력 출처 확정(S1). T0-a에는 불필요 — T0-b 착수 시.
M-T0-3개정 이력 확인 경로해결 2026-09-09. ① 공식 정의: 분류번호의 해당 자리는 「개발·개선연도」(ncs.go.kr) — 개선·보완 시점이 반영된다. ② 데이터 검증: 버전↑ → 연도 단조 상승(v1 2017.2 … v7 2023.3, r=.470)이라 '최초 개발 고정' 가설과 모순, 연도 분포가 2013–2025에 고르게 퍼져 '일괄 재발행'도 배제. → H5를 '개정 신선도'로 해석 가능. 잔여 한계: 개정의 크기는 알 수 없음(폭 측정은 과거 릴리스 본문 비교 필요, 현재 범위 밖).
M-T0-4저널T0-a: 정보·데이터 공학 계열(예: Information Processing & Management, Data & Knowledge Engineering, Government Information Quarterly — 공공 표준 데이터 품질 프레임) 또는 국내 KCI(정보과학·정보관리). T0-b: 직업교육·HRD·노동 계열(직업능력개발연구, Journal of Vocational Education & Training). 투고 전 최신 게재 경향 재확인.
