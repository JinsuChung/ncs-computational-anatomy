# The Computational Anatomy of a National Competency Standard

Code, aggregate results, and manuscripts for **"The Computational Anatomy of a National Competency Standard: Regularity, Redundancy, and Terminological Fragmentation in Korea's NCS"** (Jinsu Chung & Hanchul Ryu, Sahmyook University; manuscript v1.4, September 2026, prepared for *Information Processing & Management*).

The paper measures Korea's National Competency Standards (NCS) as *input material* for knowledge resources: how regular its sentences are, how redundant its knowledge/skill/attitude items are, how badly one concept is split across surface forms, and how much of the official taxonomy is latent in shared vocabulary. Every hypothesis was pre-registered before confirmatory testing, replicated on ESCO v1.2.1, and validated by fourteen external raters (960 judgments).

**국문 요약.** 한국 국가직무능력표준(NCS)의 텍스트를 지식 자원의 *재료*로서 전수 측정한 논문의 코드·집계·원고입니다. 문장 규칙성(99.56%), KSA 중복, 표기 파편화(규칙 8.2% → 임베딩 28.1% → 검증 19.2–23.6%), 잠재 분류 구조(NMI .33)를 사전 등록 가설로 검정하고 ESCO에서 재현했습니다.

## Reproducing

1. Obtain the NCS export **"NCS 정보망 DB (대분류별), 2026년 2월"** from the Korean public-data portal (KOGL Type 1) and place the `.xlsx` under `reference/`.
2. `docker compose up -d` (Postgres 16 on port 55432), then `python scripts/import_ncs_xlsx.py --file reference/<export>.xlsx`.
3. `pip install -r requirements.txt`, then run the scripts in the table above in order. Embeddings use `BAAI/bge-m3` (HF revision `5617a9f6`) and `intfloat/multilingual-e5-large` (`3d7cfbda`) via sentence-transformers 5.1.2 / torch 2.8.0; a GPU or Apple-silicon MPS device is recommended (326,592 keys).
4. For the ESCO replication, download the ESCO v1.2.1 English CSV distribution from the European Commission and run `scripts/esco_load_csv.py` then `esco_replication.py`.

Random seeds are fixed in the scripts (`SEED = 20260909`); Louvain results are reported with the range over ten seeds.

## Validation-tier convention

Every number in the paper and in these outputs is tagged by how it was obtained: **source** (deterministic census statistics), **model-assisted** (embedding proposals, unvalidated), or **human-validated** (external raters). Candidate merges are labelled `candidate` unless a member pair was judged.
